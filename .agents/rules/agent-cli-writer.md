# agent-cli-writer

The skill lives at `skills/agent-cli-writer/SKILL.md`. Read it there.

Reach for it when you design, write or review a command-line tool that AI
agents will operate: a new command, flag, output or error message, a tool's
help text or manual, long-running work, or agents misusing a tool.

**The rule it enforces:** every rule of the tool is stated by the tool, at the
moment it applies.
